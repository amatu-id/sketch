# Sketch Paint

Aplikasi menggambar di browser — bagian dari Portal AMATU (https://amatu-id.github.io/sketch/).

- Kuas & pensil (pensil HB/6B, arang, krayon, bolpoin, fineliner, G-pen, kaligrafi, spidol, stabilo, kuas bulat/lembut, airbrush, cat air, cat minyak, kuas kering, cat semprot, piksel, stipple, neon) dengan tekanan stylus, penghalus garis, garis putus-putus/titik.
- Penghapus berbasis kuas, jari (smudge), ember isi warna (block paint), gradien, pipet.
- Bentuk: garis, panah, kotak, elips, segitiga, poligon, bintang, hati, balon kata — garis penuh/putus-putus/titik, bisa diedit sebelum diterapkan.
- Teks dengan font, garis tepi, latar; foto, ikon & emoji sebagai lapisan yang bisa digeser/diputar/diubah ukuran.
- Lapisan: opasitas, mode campuran, kunci, kunci alfa, topeng kliping, gabung, ratakan.
- Seleksi kotak/elips/laso/tongkat ajaib, pindah & ubah, salin/tempel, filter (sketsa pensil dari foto, line art, blur, HSL, level, dll).
- Penggaris (mm/cm), simetri cermin/radial, bentuk cepat (tahan → garis lurus/lingkaran), kisi bantu.
- Kertas A-series/F4/Letter/kustom (px·mm·cm·dpi) atau kanvas tak terbatas; pola kertas kotak/titik/garis/isometrik.
- Ekspor PNG/JPG/WEBP/PDF/PSD berlapis + file proyek; simpan otomatis di perangkat (IndexedDB) + sinkron akun Portal AMATU.

Tanpa build: `index.html` + `css/` + `js/` (ES modules).
